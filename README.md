# Recipe Book

A personal recipe book that runs in the browser and works offline (installable on iPhone and Mac).

- Search by ingredients (several at once, ranked by closest match), course and meal type
- Tolerates typos and accents (saute / sauté) and knows other names for ingredients (courgette / zucchini)
- Recipes are stored on each device (IndexedDB); optional sync through a private GitHub Gist
- Share one or more recipes on WhatsApp or by email

No build step: it is plain HTML, CSS and JavaScript. Recipes are **not** stored in this repository.
